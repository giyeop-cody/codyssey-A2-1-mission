## 4. 수치미분: x^2 에서 ≤1e-4 검사는 항등식

| 함수 | 최적 h | 최적 오차 | h=1e-1 | h=1e-8 | 1e-4 전구간 통과 |
|---|---|---|---|---|---|
| x^2 | 1e-01 | 4.441e-16 | 4.441e-16 | 6.604e-09 | **O** |
| x^3 | 1e-06 | 8.027e-11 | 1.000e-02 | 7.130e-09 | X |
| sin(x) | 1e-05 | 1.114e-11 | 9.001e-04 | 2.581e-09 | X |

> x^2 은 전 h 구간에서 ≤1e-4 통과(True) → 미션의 오차 조건은 이 함수에서 **검증이 아니다**

등고선-그라디언트 직교: 그려진 곡선 기준 최대 편차 **0.8322°**, 접선을 그라디언트로 유도하면 **0.000e+00°**(항등식). 유도 접선은 편차 0(항등식, 검사로서 가치 없음). 그려진 등고선에서 재면 격자 이산화·보간으로 0.1~수 도 수준의 편차가 남 → '직교한다'고 주장하려면 이 편차와 격자 해상도를 함께 적어야 한다

그림: `figures/03_gradient_contours.png`(등고선과 그라디언트 화살표), `figures/04_optimizer_paths.png`(두 옵티마이저 경로를 같은 축에), `figures/05_lr_sweep.png`(함수별 상한) — 미션이 요구한 '하나의 Figure에 겹쳐'를 모두 지켰다.

## 6. 역전파: 손계산 = NumPy = 수치미분 (4자리)

- 관례: z1 = W1 @ x + b1 (열벡터 관례) → dW1 = outer(dz1, x). 뒤집은 관례(x @ W1)면 dW1 = outer(x, dz1) 로 전치된다
- 고정 예제: {"x": [1.0, 0.0], "W1": [[0.1, 0.2], [0.3, 0.4]], "b1": [0.0, 0.0], "W2": [0.5, 0.6], "b2": 0.0, "z1": [0.1, 0.3], "a1": [0.524979, 0.574443], "z2": 0.607155, "yhat": 0.647292}

- **y_true=1.0**: L=0.434958, ŷ=0.647292, ∂L/∂z₂=-0.352708, ∂L/∂W₁=[-0.043979, -0.0, -0.051734, -0.0], 최대상대오차(0 제외)=2.041e-10, gate ≤1e-7: True / 4자리 일치: True
- **y_true=0.0**: L=1.042114, ŷ=0.647292, ∂L/∂z₂=0.647292, ∂L/∂W₁=[0.08071, 0.0, 0.094941, 0.0], 최대상대오차(0 제외)=2.696e-10, gate ≤1e-7: True / 4자리 일치: True

- 미션 고정 예제는 y_true 를 적지 않았다 → 1.0/0.0 **양쪽** 손계산을 싣고, 리포트·노트북은 y_true=1.0 을 표준으로 삼는다(근거: 문서 01 결정 문단)
- x=[1,0] 때문. 오동작이 아니라 입력 결핍 → '0이 아닌 항이 있다' 검사가 필요하다 (0인 열 1개)
