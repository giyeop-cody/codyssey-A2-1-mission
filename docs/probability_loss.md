# 손실 함수는 가정의 결론이다 (A2-1-T9)

## 1. MSE = MLE (정규 오차 가정)

모델 `ŷ = f(x)` 의 오차가 `ε ~ N(0, σ²)` 이면

1. `p(y|x) = (1/(σ√(2π))) exp(−(y−f(x))²/(2σ²))`
2. 로그우도 `ℓ = −(N/2)log(2πσ²) − (1/(2σ²)) Σ (yᵢ−f(xᵢ))²`
3. σ·상수는 f 에 무관 ⇒ **ℓ 최대 ⇔ Σ(yᵢ−f)² 최소 ⇔ MSE 최소**
4. 실측(n=200, 시드 42, 격자 0.001): 기울기 argmin(MSE)=**1.486**, argmax(ℓ)=**1.486**, 차이 **0.000e+00**

## 2. 교차엔트로피 = MLE (베르누이)

1. `p(y|p) = p^y (1−p)^(1−y)` ⇒ `log p` 의 기댓값 = `−[y log p + (1−y) log(1−p)]` = BCE
2. N개 표본의 로그우도 합 = `−N · BCE` ⇒ **BCE 최소 ⇔ 우도 최대**
3. 실측(500회, p_true=0.35): MLE p̂ = **0.348**, BCE argmin p̂ = **0.348**, 차이 **0.000e+00**
4. 엔트로피 관계: 참값 기준 CE = **0.647455** ≥ H(p) = **0.647447** (깁스 성립).
   반면 **표본의 플러그인 엔트로피는 0.6462** 로 H(p) 보다 **−0.0012 작다** →
   "모델 손실이 엔트로피보다 크면 이상하다"는 문장은 표본 기준으로는 **거짓**이다(추정 편향).

## 3. softmax 수치 안정성

`softmax(z) = exp(z−max z)/Σexp(z−max z)` 는 원본과 **완전히 같은 값**(차이 1.110e-16)이지만,
`z×1000` 에서 차감 없는 쪽은 `inf/inf → nan`, 차감 있는 쪽은 `[0,0,1]` 유한.
⇒ **작은 스케일에서는 이 '개선'을 검증할 수 없다.** 안정화 검사에 큰 logits 케이스를 일부러 넣는 이유다.

## 4. 그래서 리포트에 쓰는 문장

"MSE 를 쓴 것은 선택이 아니라 **오차를 정규분포로 본 결과**이고, 이 동치는 σ 를 고정하고 격자 0.001 위에서 성립한다.
격자를 0.1 로 굵히면 두 argmin 은 어긋난다(측정되지 않은 일반화 문장은 쓰지 않는다)."
