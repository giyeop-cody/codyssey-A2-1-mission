# y_true 가 정의돼 있지 않다 (A2-1-T8)

미션 원문 §4-3 의 고정 예제는 `x=[1,0]`, `W1=[[.1,.2],[.3,.4]]`, `b1=0`, `W2=[.5,.6]`, `b2=0`, Sigmoid, BCE 까지 주고
**`정답: y_true =` 칸을 비워 두었다**(원문 그대로 값이 없다). 손실과 모든 역전파 항은 y 에 따라 값이 달라지므로,
정의 없이 "L=0.434958" 만 쓰면 채점자가 다른 y 를 가정했을 때 숫자가 맞지 않는다.

## 양쪽 계산 (같은 순전파, ŷ = 0.647292)

| y_true | L = −[y log ŷ + (1−y)log(1−ŷ)] | ∂L/∂ŷ | ∂L/∂z₂ = ŷ − y | ∂L/∂W₂ = a₁·dz₂ | ∂L/∂W₁ (행 우선) |
|---|---|---|---|---|---|
| **1.0** | 0.434958 | −1.544899 | **−0.352708** | [−0.185165, −0.202611] | [−0.043979, 0, −0.051734, 0] |
| 0.0 | 1.042114 | +2.835203 | +0.647292 | [+0.339815, +0.371832] | [+0.080710, 0, +0.094941, 0] |

- 값 출처: `reports/backprop.json`(NumPy 해석 기울기, 수치미분과 상대오차 ≤2.7e-10).
- 노트북 §3·§4·§7 의 **손계산**은 매 단계를 소수 6자리로 반올림하며 진행하므로 6번째 자리가 1 정도 다를 수 있다
  (예: y=0 의 L 은 손계산 1.042115 / 정밀값 1.042114). 원문 기준인 **소수 4자리**에서는 전부 일치한다(노트북 §5·§7 의 비교표).
- ∂L/∂W₁ 의 둘째 열이 0 인 것은 y 와 무관하다: x₂=0 이라 `∂L/∂W₁ = δ₁ xᵀ` 의 둘째 열이 사라진다(오류가 아니라 입력 결핍).

## 선택과 근거 (정정됨)

- **표준: y_true = 1.0.** 근거는 *관례적 선택*일 뿐이다: 원문은 값을 주지 않았고, 원문 어디에도 기대 손실값이나 기대 기울기 같은
  **참고 숫자가 없다.** (2026-10-11 재검증에서 정정 — 이전 판은 "미션이 예시로 제시한 숫자가 L=0.434958 급"이라고 적었지만,
  원문에는 그런 숫자가 없다. 이 레포가 스스로 계산한 값을 원문의 근거처럼 쓴 순환 논증이었다.)
- 그래서 **두 줄을 다 제출**한다. 노트북(§3–§5 는 y=1, §7 은 y=0 전체 손계산 + NumPy 대조), `reports/backprop.json`,
  이 문서가 양쪽을 모두 담는다. 채점자가 y=0 을 가정해도 비교할 표가 있다.
- y 를 바꿔도 변하지 않는 것: 순전파 중간값(z₁, a₁, z₂, ŷ), shape, 기울기 0 인 열. 변하는 것: L 과 ∂L/∂ŷ 이하 모든 역전파 항
  (∂L/∂z₂ = ŷ − y 이므로 y=0→1 로 바꾸면 정확히 1 만큼 이동).

> 원칙: 정의가 비어 있으면 "가정했습니다"로 끝내지 않고 **양쪽을 계산해 차이로 설명**한다. 그리고 가정의 근거를 원문에서 찾을 수 없으면
> "근거 없음 — 관례"라고 적는다.
